Доступ к сохранению

Чтобы изменения попали на сайт, нужен GitHub токен. Создаётся один раз на компьютер, хранится в браузере.

📖 Как получить токен (1 минута)
  1. Открой github.com → Settings → Tokens (fine-grained)
  2. Token name: Веди CMS
  3. Expiration: 90 days (или больше)
  4. Repository access: Only select repositories → antonkuzmenkov/moyvedi
  5. Permissions → Repository permissions → Contents: Read and write
  6. Кнопка «Generate token» → скопируй (начинается с github_pat_)
  7. Вставь сюда ↓
